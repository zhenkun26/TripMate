# Design

## Scope

Correct shell working directories, remove the unavailable multi-architecture script claim, and describe ticket fallback estimates accurately.

## Decisions

Use current tracked source and configuration as evidence. Keep fixes local to the affected instructions; do not imply successful runtime validation. Commands remain documentation and are not executed for this change.

## Validation

Review the exact diff, bilingual parity, fenced code blocks, relative link targets, and command working directories. Strict OpenSpec validation requires an available CLI; absence must be reported rather than called a pass.

## Boundaries

Preserve all existing authorization, source attribution, and acceptance limitations. Submit for review as a draft; do not merge, deploy, synchronize main specs, or archive.
